# Base Admin Dashboard

React admin SPA integrated with Laravel (Sanctum + Reverb).

## Setup

```bash
cp .env.example .env
npm install --legacy-peer-deps
npm run dev
```

## Docs

See [`../../docs/README.md`](../../docs/README.md) at the repo root.

## Stack

React 18 · Vite · TanStack Query · Axios · React Hook Form · Zod · Tailwind · AG Grid · i18next (en/ar)
